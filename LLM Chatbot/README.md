# LLM Chatbot Using Transformer-Based LLM

## Aim
To develop an interactive chatbot using a pre-trained
Transformer-based Large Language Model.

## Model
Qwen/Qwen2.5-0.5B-Instruct

## Technologies Used
- Python
- PyTorch
- Hugging Face Transformers
- Gradio

## Features
- Interactive chatbot interface
- Context-aware conversation history
- Adjustable temperature
- Adjustable maximum output length
